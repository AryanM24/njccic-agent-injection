# Phases A–E — Study instruments, pipeline variants, corpus, models, figures: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the brief's Phases A–E (offline instruments, relay/handoff/gate arms, corpus extensions, model registry and cost, figures and docs) on top of the finished Phase 0 base, in one study with no protocol split.

**Architecture:** Three sequential foundation tasks fix the shared shapes everything else reads: doc 11 §§3–7, the four new task conditions (plumbed, validated, hashed, swept), and the pipeline's `stages` list with relays. Work then runs in six worktree lanes in three waves (max three lanes at once) with disjoint file ownership, followed by sequential integration (merge, regenerate the public corpus once, smoke-test every script on a mockllm log, figures, docs, audit close). The offline monitor (A3) is the single rule definition; the runtime gate (B3) imports it.

**Tech Stack:** Python 3.11, Inspect AI 0.3.255 (installed wheel; `ResponseSchema` structured output, `mockllm/model`), pydantic, pytest, ruff 0.16.5, mypy 2.3.1, `analysis` extra (statsmodels, scikit-learn, pandas, numpy, matplotlib).

## Rulings this plan makes (record each in doc 11 §8 "Rulings" and tell the PI)

1. **`typed_spotlight` is not a separate handoff mode.** Spotlighting already exists as `defense="spotlight"` (v2). `HANDOFF_MODES = ("free_text", "typed")`; the brief's "typed + spotlight" arm is `handoff_mode="typed", defense="spotlight"`. One spotlight definition.
2. **Typed handoff replaces the free-text facts block.** `handoff_mode="typed"` with `identity_mode="facts"` is refused (redundant: the trusted block is built from the same directory data); `typed` + `guard` = trusted block + v2 tool guard.
3. **GEE working correlation.** v2 (doc 10 §5) chose independence + bias-reduced SEs; the brief says exchangeable. Plan: exchangeable robust is primary (brief), independence + bias-reduced is reported beside it as a sensitivity column. Flagged to the PI as a doc-10-vs-brief disagreement.
4. **Record documents come from `metadata["runs"][label]["document_text"]`** (Phase 0), un-datamarked, not re-extracted. `doc_unavailable` means that key is absent.
5. **`stages` replaces `h1`/`h2`.** `run_pipeline` returns `stages`, `final`, `stage3_messages`, `status`; every reader goes through Phase 0's `stage_texts`, whose `h1`/`h2` fallback is deleted.
6. **`--model-preset` is the one flag;** `--preset` stays as an argparse alias of the same option (same `dest`), so existing commands keep working and there is one code path. `-M` still overrides the provider pin.
7. **Gate scope = the A2 sink table** (includes W3 `get_student_record`, a read sink), blocking on any violated rule that applies to the call. One rule set, no "blocking" flag.

## Review Focus

1. **An assistant message with two tool calls, or a call Inspect rejected before the tool ran (bad args → no ledger entry).** Records must attach each result and ledger outcome to the right call; an unmatched call gets outcome `not_executed`, never a neighbour's result. Test in Task 4.
2. **Values that differ only by case, whitespace, angle brackets or a prefix-substring** (`" s-88214 "` vs `S-88214`; `Dana <dana@x.org>`; `S-8821` inside `S-88214`). Provenance must normalize through the same extractors and match whole tokens only. Test in Task 5.
3. **A typed handoff wrapped in a ```json fence, or with an extra key.** A single fence is stripped (not a retry); an extra key or invalid JSON is `handoff_parse_error`, the run stops, and every scorer reports NaN. Test in Task 11.
4. **A pre-C1 `payloads.py` on the PI's workstation (no component markers).** `load_gated_payloads()` raises a `ValueError` naming the workflow, goal and missing marker; the Tier-1 guard still scans (it reads raw texts without validating). Test in Task 7.
5. **Degenerate data in fits:** all-zero outcome cells (separation), a CV fold with one class, survival with no decay (s = 1). GEE returns None, AUROC is NaN, half-life is `inf` — never a crash or a fake number. Tests in Tasks 14, 15, 17.
