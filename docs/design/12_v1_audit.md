# First-Edition Audit

**STATUS: DRAFT v0.2 (2026-11-14). Not signed. Not in force.** Recorded in
`config.DOC_VERSIONS` as `v1_audit = "0.2-draft"`. This is the audit the brief
(`docs/superpowers/plans/2026-11-14-v3-brief.md` §2) calls "doc 11"; under the
PI's numbering ruling it is doc 12. The study design it feeds is
`11_study_design.md`; the recipient and tier policy is
`13_recipient_policy_addendum.md`.

## 1. Scope and rulings

Every problem found in the first edition, and every open item carried from the
second-edition draft (doc 10), gets one row. The PI rulings of 2026-11-14 apply
throughout:

1. **One study.** The first edition, the second edition (doc 10) and the v3
   brief are one combined study. There is no `protocol` parameter, no frozen
   first-edition path, no golden first-edition test, and no analysis of old
   logs: every run is redone. Brief rules 2 and 3 are waived. A "fix" below
   replaces the old behaviour; it is never kept alongside it.
2. The study builds on everything in the second edition (identity_mode
   facts/guard, spotlight defense, task facts, statistics, presets, canaries).
3. Doc numbering: doc 10 stays the second-edition draft; doc 11 is the study
   design; doc 12 is this audit; doc 13 is the recipient policy addendum.
4. Destructive changes to old data and corpus are allowed.

Release policy (doc 05): this document names no payload wording and gives no
rate broken down by concealment channel, file type or goal. Tier 1 material is
referred to by location only.

## 2. Status values

Every row ends in exactly one of `fixed`, `partially fixed`, `won't fix
(reason)` or `needs a decision from me` (`test_audit_rows_have_final_status`).
Phase 0 closed every row; v0.2 updates them for everything Phases A–E built.
The Test column names the tests that cover the row where one exists.
`partially fixed` rows say in the Fix column what is built and what remains:
a run, a write-up step, or a decision.

Evidence abbreviations follow `docs/superpowers/plans/2026-11-14-audit-sources.md`
(the source digest; `src #n` cites its row n): IM = `implementation-map.md`,
FND = `findings.md`, PRG = `progress.md`, HO = `HANDOFF.md`, DEV =
`attestations/preregistration_deviations.md`, D10 = doc 10, PLAN =
`docs/isef-v2-plan.md`, PAPER = `paper/main.tex`, BRIEF = the v3 brief.
